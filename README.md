# Praktikum Python 1 — Program Identitas

Program Python sederhana untuk menampilkan identitas diri menggunakan variabel dan fungsi `print()`.

## 📌 Tentang Program

Program ini dibuat sebagai bagian dari kegiatan praktikum Python. Program menyimpan beberapa informasi identitas ke dalam variabel, kemudian menampilkannya melalui terminal.

## 🛠️ Konsep yang Digunakan

* Variabel
* Tipe data `string`
* Tipe data `integer`
* Fungsi `print()`
* Output melalui terminal

## 💻 Source Code

File utama dalam project ini:

```text
identitas.py
```

Program menyimpan data seperti:

* Nama
* NIM
* Tempat dan tanggal lahir
* Jenis kelamin
* Hobi

Kemudian seluruh data tersebut ditampilkan menggunakan fungsi `print()`.

## ▶️ Cara Menjalankan

Pastikan Python sudah terinstall pada perangkat.

Jalankan file dengan perintah:

```bash
python identitas.py
```

## 📤 Contoh Output

```text
Nama : Alsya Kanaya Dzikra
NIM : 2605060075
Tempat Tanggal Lahir : Magelang, 12 Oktober 2007
Jenis Kelamin : Perempuan
Hobi : Coding & Gaming
```
